# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public GitHub issue,
discussion, pull request, or social-media post.

Send a private report to:

shogoa24@gmail.com

Include the following where possible:

- the affected page, endpoint, feature, or component;
- clear reproduction steps;
- the security impact and who may be affected;
- screenshots or request details with credentials and personal data removed;
- a suggested mitigation, if you have one.

Do not include passwords, API keys, session tokens, private user content, or
other people's personal data in the report.

## Response

The maintainer will review reports within available capacity, confirm whether
the issue can be reproduced, and prioritize a fix according to its impact. This
policy does not promise a response time, resolution time, service level, bounty,
or reward.

## Scope

Reports about the current Lyra application and this repository are welcome.
Third-party services, libraries, AI providers, AWS, Stripe, and user-operated
environments may have their own reporting processes and policies.
