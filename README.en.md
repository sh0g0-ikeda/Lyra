# Lyra | AI Manga Creation Editor

[Japanese README](README.md) | [Official site](https://lyra-japan-manga.com/) | [Pricing](https://lyra-japan-manga.com/pricing) | [Examples](https://lyra-japan-manga.com/examples) | [Web app](https://app.lyra-editor.com/) | [App Store](https://apps.apple.com/jp/app/lyra-mobile/id6797564060) | [Google Play](https://play.google.com/store/apps/details?id=com.lyra.mobile)

Lyra is an AI manga creation editor that turns a story into editable manga pages. It organizes works, characters, stories, scenes, pages, panels, and dialogue so that creators can review and revise AI suggestions before generating a page.

## What you can do

- Develop a story into chapters, episodes, pages, and panels.
- Manage character settings, reference images, aliases, and reusable work materials.
- Edit characters, scene context, composition, camera, backgrounds, sound effects, and dialogue by panel.
- Generate pages from saved inputs, monitor asynchronous jobs, retry failures, and save page images. The Web app also supports PDF export.

## Typical workflow

1. Create a work, chapters, episodes, and characters.
2. Confirm character reference images and plan pages and panels from the story.
3. Review and revise panel-level content before generation.
4. Generate pages and export the selected pages or full work.

## Pricing, commercial use, and limits

See the [pricing page](https://lyra-japan-manga.com/pricing) for current conditions. Free registration includes 30 credits. Page generation starts at 3 credits; each reference image from the fourth onward adds 1 credit; generating a character reference image costs 1 credit. Costs vary with settings and processing.

Commercial use, including publishing and selling doujinshi and e-books, is permitted. Users must confirm third-party rights and publishing-platform rules. Lyra does not guarantee that copyright will arise in generated output or that output will not infringe third-party rights. Faces and clothing can vary between generations, so review and revise generated results as needed.
